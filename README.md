## Introducción  
Este documento proporciona las instrucciones necesarias para compilar y ejecutar el trabajo práctico. Se incluyen los requisitos del sistema, el proceso de instalación y una guía de uso.  

---

## Requisitos Previos  
Para compilar y ejecutar el programa, necesitará:  
- **Compilador de C++**  
- **Make**  
- **SDL2**, **SDL2_image**, **SDL2_ttf**, y **SDL2_mixer**  
- **pthread**  
- **yaml**  

---

## Instalación de Dependencias  
Para sistemas basados en Debian/Ubuntu, ejecute los siguientes comandos en la terminal:  
```bash
sudo apt update
sudo apt install libsdl2-dev libsdl2-image-dev libsdl2-ttf-dev libsdl2-mixer-dev libyaml-cpp-dev
```
